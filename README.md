# JIE-Weihnachtsfest-26-Rallye

Die Punsch-Rallye: Web-App für die Weihnachts-Schnitzeljagd der JIE-Laufgruppe in Jena.

- Die App ist eine einzige Datei: `index.html`.
- Sie liegt auf dem Branch `gh-pages` und wird von GitHub Pages ausgeliefert.
- Inhalte (Teams, Stationen, Fragen, Sidequests, Codes) stehen oben im Skript im Block „INHALTE“.

Stand: Prototyp. Die anderen Teams werden noch simuliert, Punkte und Fotos liegen nur auf dem jeweiligen Handy.
